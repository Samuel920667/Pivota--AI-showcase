# Pivota--AI-showcase
Next-generation fintech application featuring zero-latency peer-to-peer transfers, intelligent expense splitting, and a FastAPI-driven real-time fraud risk engine. Built with React Native (Expo Router), Node.js/PostgreSQL, and Python AI microservices.

Pivota is a full-stack, AI-enhanced digital wallet and payment application designed to make everyday transactions fast, intuitive, and secure. Built with a mobile-first architecture, Pivota combines smooth consumer payments with machine-learning fraud intelligence.

Key Features

Instant P2P Transfers: Direct wallet-to-wallet transfers with atomic transactions and strict ledger consistency.

Smart Bill Splitting: Dynamic group request flows allowing participants to review, approve, and settle individual shares seamlessly.

AI Shield & Heatmap: A Python-powered fraud detection microservice that analyzes transactions in real time based on location telemetry and anomaly scoring.

Live Notifications & Requests: Real-time money request polling, member verification, and instant status updates.

Tech Stack

Frontend: React Native, Expo Router, TypeScript

Backend: Node.js, Express, PostgreSQL

AI/ML Engine: Python, FastAPI, Uvicorn

Payments: Flutterwave API Integration
